
# AI-Powered Loan Screening and Risk Assessment Agent

## Business Problem
Banks spend significant time reviewing loan applications. This agent automates preliminary screening.

## Agent Workflow
1. Read uploaded loan data.
2. Calculate risk indicators.
3. Assess applicant risk.
4. Recommend Approve, Manual Review, or Reject.
5. Produce downloadable results.

## Run
pip install -r requirements.txt
streamlit run app.py
